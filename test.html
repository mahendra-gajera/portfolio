⛓️ LangChain vs LangGraph

Two libraries. One rules them both, the other lets them argue · Simplified by Mahendra Gajera

💡 Pipeline vs State Machine

Both come from the LangChain team but solve different shapes of problems. The simplest mental model: LangChain is a Unix pipe, LangGraph is a flowchart with memory.

🌊 LangChain (The Pipeline)
Prompt → LLM → Parser
• Linear data flow
• Highly composable (LCEL)
• Fast & parallelizable
• No loops or shared state
= Unix pipe (cat | grep)
🔄 LangGraph (The State Machine)
Nodes + Conditional Edges
• Shared persistent state
• Built for cyclic loops
• Multi-agent routing
• Time-travel debugging
= Flowchart with memory

⚖️ The Decision Matrix

When to use LangChain: RAG pipelines, summarization, extraction.
Rule of thumb: One pass, one shape. No state to maintain. Use LCEL for free streaming and speed.

When to use LangGraph: Multi-agent systems, Human-in-the-loop, ReAct loops.
Rule of thumb: Reach for it the moment you write "if X, retry" or "loop until done".
